# Projeto-Teste-Manuais
Resumo do Teste Manual

Objetivo: Realizar testes manuais no site da empresa para garantir que todas as funcionalidades estejam operando conforme o esperado e identificar possíveis problemas.

Processo:

Planejamento:

Definição dos critérios de teste e criação de casos de teste com base nos requisitos do site.
Execução dos Testes:

Navegação por todas as páginas do site para verificar a funcionalidade de links, formulários, botões e outros elementos interativos.
Teste de diferentes cenários, incluindo entradas válidas e inválidas, para avaliar a resposta do sistema.
Verificação da compatibilidade em diferentes navegadores e dispositivos.
Relatório de Evidências:

Documentação detalhada dos testes realizados, incluindo capturas de tela e descrições dos passos seguidos.
Registro de comportamentos esperados versus comportamentos observados para facilitar a identificação de problemas.
Bug Report:

Identificação e descrição de quaisquer falhas ou bugs encontrados durante os testes.
Relato das condições em que os bugs foram detectados, impacto potencial e sugestões para correção.
Conclusão: Os testes manuais foram concluídos com sucesso, e todas as evidências e relatórios de bugs foram devidamente documentados e comunicados à equipe de desenvolvimento para ações corretivas.
